# Reusable prompts

Prompts to paste into Claude Code. They are not skills: nothing loads them automatically, and they work in any repository.

Each prompt has its own folder:

- `prompt.md` holds the prompt to copy.
- `examples/` holds runs that show when to use the prompt and what Claude produced.

| Prompt | Use it to |
|---|---|
| [stop-hook-checks](stop-hook-checks/prompt.md) | Make Claude rerun lint, type checks and tests before it stops, and fix what fails |
